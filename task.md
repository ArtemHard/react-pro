Общие рекомендации 
● Не используйте useState, если это не требуется. 
● Все временные значения и счетчики храните через useRef. 
● Проверяйте, что компоненты не перерисовываются при обновлении ref. 
Основная часть (до 9 баллов) 
1. Компонент ClickTimer (3 балла) 
Создайте компонент ClickTimer, в котором: 
● Время первого клика сохраняется через useRef. 
● Каждое последующее нажатие отображает в консоли: 
○ разницу между текущим временем и временем первого клика; 
○ общее количество кликов. 
Рекомендации 
● Используйте Date.now() для замеров. 
● В useRef храните и timestamp, и счетчик. 
● Не используйте useState — все через useRef. 
Хорошая практика — явно задать интерфейс для значения, хранимого в ref. Это 
улучшает читаемость, автодополнение и предотвращает ошибки. Например: 
interface ClickData { 
startTime: number | null; 
clickCount: number; 
} 
const clickDataRef = useRef<ClickData>({ 
startTime: null, 
clickCount: 0, 
}); 
Критерии 
● Время первого клика фиксируется через ref — 1 балл. 
● Счетчик кликов хранится в ref, не вызывая ререндер — 1 балл. 
● В консоли отображается разница во времени и общее количество — 1 балл.

3. Компонент FocusTracker (3 балла) 
Задание 
Создайте компонент FocusTracker, в котором: 
● Есть два поля ввода и одна кнопка «Сфокусировать на первом». 
● При нажатии на кнопку фокус устанавливается на первое поле. 
● В консоли отображается, сколько раз происходил переход фокуса между полями 
(используйте onFocus). 
Рекомендации 
● Для каждого <input> используйте useRef, чтобы привязаться к DOM-элементу. 
● Для счетчика переходов используйте useRef (не useState). 
● Ловите событие onFocus или onFocusCapture для отслеживания перехода. 
Как точно отследить именно переходы между полями 
● onFocus срабатывает даже при первом автозапуске (autoFocus или focus() из 
useEffect). 
● Чтобы не считать начальный фокус, можно: 
○ использовать onFocusCapture (срабатывает раньше, подходит для точного 
контроля); 
○ или проверять event.relatedTarget — это элемент, с которого ушел 
фокус: 
const handleFocus = (event: React.FocusEvent<HTMLInputElement>) => 
{ 
if (event.relatedTarget) { 
// Фокус действительно перешел с другого элемента 
ref.current!.clickCount += 1; 
} 
}; 
Критерии 
● Установка фокуса работает через ref.current.focus() — 1 балл. 
● Переход фокуса отслеживается через onFocus — 1 балл. 
● Количество фокус-переходов корректно отображается в консоли — 1 балл.

2. Компонент WebSocketLogger (1.5 балла) 
Задание 
Создайте компонент WebSocketLogger, который: 
● При монтировании устанавливает WebSocket-соединение. 
● Подписывается на входящие сообщения и логирует их в консоль. 
● Сохраняет WebSocket в ref, не используя useState.

Рекомендации

Критерии 
● Соединение хранится в ref, а не в state — 0.5 балла. 
● WebSocket создается один раз при монтировании — 0.5 балла. 
● Соединение корректно закрывается в cleanup — 0.5 балла.
